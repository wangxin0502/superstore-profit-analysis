# Superstore 超市利润诊断项目 · 数据字典

## 数据来源

基于 Kaggle 经典 Superstore 数据集结构生成，模拟美国某连锁超市 2015-2018 年订单交易数据。

## 基本信息

- **文件**：`superstore.csv`（UTF-8 编码，逗号分隔）
- **行数**：9,994 行（每行 = 1 笔订单）
- **列数**：21 列
- **时间跨度**：2015-01-03 ~ 2018-12-28（4 年整）
- **整体规模**：总销售额约 $4.10M，总利润约 $0.67M，整体利润率 16.3%

## 字段说明

### 订单与物流

| 字段         | 类型   | 说明                                                                  |
| ---------- | ---- | ------------------------------------------------------------------- |
| Row ID     | int  | 行号，1-9994                                                           |
| Order ID   | str  | 订单号，如 `CA-2017-100234`，同一订单可能有多个子订单                                 |
| Order Date | date | 下单日期，格式 `MM/DD/YYYY`                                                |
| Ship Date  | date | 发货日期，格式 `MM/DD/YYYY`，恒 ≥ Order Date                                 |
| Ship Mode  | str  | 发货方式：`Standard Class` / `Second Class` / `First Class` / `Same Day` |

### 客户

| 字段            | 类型  | 说明                                            |
| ------------- | --- | --------------------------------------------- |
| Customer ID   | str | 客户编号，如 `XX-10023`，共 800 名客户                   |
| Customer Name | str | 客户名，如 `Customer_23`                           |
| Segment       | str | 客户分群：`Consumer` / `Corporate` / `Home Office` |

### 地理

| 字段          | 类型  | 说明                                       |
| ----------- | --- | ---------------------------------------- |
| Country     | str | 国家（统一 United States）                     |
| City        | str | 城市                                       |
| State       | str | 州，共 30 个州                                |
| Postal Code | str | 邮编                                       |
| Region      | str | 大区：`West` / `East` / `South` / `Central` |

### 商品

| 字段           | 类型  | 说明                                                |
| ------------ | --- | ------------------------------------------------- |
| Product ID   | str | 商品编号，如 `PROD-TEC-0001`                            |
| Category     | str | 大类：`Technology` / `Furniture` / `Office Supplies` |
| Sub-Category | str | 小类，共 17 种，详见下表                                    |
| Product Name | str | 商品名                                               |

### 财务

| 字段       | 类型    | 说明                    |
| -------- | ----- | --------------------- |
| Sales    | float | 销售额（美元），单价×数量×(1-折扣)  |
| Quantity | int   | 购买数量，1-10             |
| Discount | float | 折扣率，0-0.9（0 表示无折扣）    |
| Profit   | float | 利润（美元），**可为负数**（表示亏损） |

## 关键业务口径

- **利润率** = SUM(Profit) / SUM(Sales)
- **平均客单价** = SUM(Sales) / COUNT(DISTINCT Order ID)
- **旺季**：通常 10-12 月（Q4）
- **淡季**：通常 1-3 月（Q1）

## 已知的数据结论（供你验证）

- **Technology** 销售占比最高（约 66%），利润率约 24%
- **Furniture** 销售额占比约 24%，**但整体亏损**（利润率 -3.5%），是主要亏损源
- **Tables / Bookcases** 子品类在高折扣场景下常出现负利润
- 高折扣（≥45%）订单整体亏损概率显著提升
- 部分州持续亏损，部分州稳定盈利

## 数据质量特点

- 无缺失值（干净数据）
- 无重复 Row ID
- 同一 Order ID 可能出现在多行（一个订单多个子项），需 GROUP BY 聚合
- Ship Date - Order Date 通常 1-7 天，可用于计算发货时效
